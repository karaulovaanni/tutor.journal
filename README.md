# Журнал Ани

Личный журнал занятий по математике. GitHub Pages хранит только интерфейс, записи учеников находятся в Firebase Firestore и загружаются после входа.

## Структура

- `index.html` — главная точка входа.
- `assets/css/` — оформление.
- `assets/js/` — интерфейс, вход и синхронизация.
- `assets/images/` — иллюстрации и иконка.

Для первой загрузки войдите и импортируйте `journal-data.json` из личного архива через «Восстановить». Файл с данными учеников в публичный репозиторий не добавляется.

Работа с репетитором и освоение отмечаются независимо. Школьный план не подтверждает факт проведения урока. История изменений сохраняется в данных.

При ошибке сохранения скачайте резервную копию через «Данные». Перед закрытием дождитесь подтверждения Firebase. При одновременном изменении с двух устройств сайт предупреждает о конфликте вместо перезаписи.
